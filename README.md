# 🥫 无聊罐头 · 项目说明

**一句话**：一个单文件网页，里面装了 9 个"无聊到治愈"的小玩具。卖的是情绪价值，边际成本为零，闲鱼抖音双渠道可卖。

---

## 文件清单

```
无聊罐头/
├── 无聊罐头.html                    ← 核心产品。发给买家就是发这个文件
├── README.md                        ← 本文件
├── cdp_shot.py                      ← 商品图重生成脚本（改版后跑一下，自动重出全部截图）
├── 验收截图/                         ← 12张高清商品图（已通过视觉验收，可直接当闲鱼主图）
│   ├── hero.png      封面罐头（首图推荐）
│   ├── woodfish.png / bubble.png / stone.png / rain.png / poke.png
│   ├── noodle.png / kiddy.png / brush.png / radio.png / trophy.png（成就墙=最容易被转发的图）
│   └── dark-kiddy.png 被窝模式（发图时配文案"还有被窝模式"）
└── 卖货三件套/
    ├── 01-闲鱼文案（直接复制就能发）.md
    ├── 02-抖音引流脚本（3条）.md
    └── 03-运营SOP（定价话术交付防坑）.md
```

**你只需要做三件事**：
1. 手机浏览器打开 `无聊罐头.html` 玩一遍
2. 把 `验收截图/` 里的图传上闲鱼当商品图（首图用 hero.png）
3. 打开 `卖货三件套/01` 复制文案上架，`02` 照着拍 3 条抖音

## 产品里有什么

| 玩具 | 玩法 | 多巴胺点 |
|------|------|----------|
| 🪵 电子木鱼 | 敲一下功德+1 | 音效+飘字+连击彩蛋 |
| 🫧 无限泡泡纸 | 按住滑过去连捏 | 捏爆音效随机音高，捏完自动补货 |
| 🪨 云养石头 | 点它、给它改名 | 它从不回应你，但会陪你计时发呆 |

| 👉 戳这里 | 按一个没用按钮 | 戳"没了"后的9级文案状态机 |
| 🍜 泡一碗面 | 烧水→等3分钟→吃 | 可以快进——"这是你的面，你说了算" |
| 🚗 电子摇摇车 | 投币，车摇32秒 | 实时合成的《两只老虎》八音盒 |

**系统层**：无聊值（全站计数）、9个成就徽章（设计出来就是为了让人截图发圈）、被窝深色模式、localStorage存档、音效全部 Web Audio 实时合成（**零外部资源、零联网**，单文件即全部）。

## 技术规格（买家会问就甩这段）

- 单 HTML 文件，约 57 KB，无任何外部依赖（无CDN/无图片/无音频文件）
- 音效为 Web Audio API 实时合成：木鱼=双振荡器衰减、泡泡=带通噪声脉冲、摇摇车=正弦波旋律调度、雨声=低通白噪+随机滴答
- 适配：手机（触屏 pointer 事件+防双击缩放+safe-area）/ 电脑 / 平板；深色模式
- 数据存 localStorage，key 为 `boring_can_v1`
- 兼容性兜底：货架跳转带平滑滚动检测兜底，WebView 环境也能正常导航

## 定制入口（两处，都在 HTML 文件开头 script 部分）

1. **刻名字**：搜 `OWNER_NAME`，引号里写"给xxx的罐头"，页面底部和标题就会带名字
2. **专属语录**：搜 `radioLines`，往数组里加一行你写的话，收音机会随机播到

详细操作步骤在 `卖货三件套/03-运营SOP` 第二节。

---

## URL 参数（小功能，也是运营工具）

- `无聊罐头.html?theme=dark` —— 直接进被窝模式
- `无聊罐头.html?go=kiddy` —— 打开后直达摇摇车（评论区发"直达链接"用）
- `无聊罐头.html?only=rain` —— 单罐头模式，只显示雨窗一个区块（录短视频构图更干净）
- 组合示例：`?theme=dark&only=radio` 深色单开收音机
- `cdp_shot.py` 用的就是这些参数：改版后运行 `python3 cdp_shot.py` 一键重出 12 张商品图

## 本地预览方法

直接双击 `无聊罐头.html` 就能用默认浏览器打开（无需服务器）。

## 更新玩法（做"终身更新"承诺时用）

想加新玩具时，照着现有 section 结构复制一个区块+一段 JS 就行。候选新玩具（按实现难度排序）：
- 电子挤痘痘（大泡泡纸变体，一小时搞定）
- 云监工洗衣机滚筒（旋转 canvas）
- 电子开锁/转笔
- 白噪音扩展页（篝火/海浪/风扇，全合成，无素材）

每次更新后给老买家补发，就是"终身更新"承诺的兑现，也是复购和好评的来源。
