## 一、商品交付流程（买家拍下后你要做的事）

### 普通款交付（9.9 / 19.9）
1. 把 `无聊罐头.html` 这个单文件，通过闲鱼聊天直接发给买家（闲鱼支持发文件；如果不稳，发网盘链接）。
2. 附一句标准话术：

```
谢谢你收养这罐无聊🥫
打开方式：手机/电脑浏览器直接打开这个文件就能玩（不用联网，不用下载App）。
小贴士：
- 右上角 🌙 是"被窝模式"，睡前开
- 右上角 🔊 是音效开关，木鱼和摇摇车记得开声音
- 你所有的进度都自动保存在这台设备上
有任何打不开的情况随时找我，秒回。
```

3. 交付完隔天可追一句："今天摸鱼的时候开了吗？"（提升复购好评率，别多问，一句就够）

### 定制款交付（29.9，刻名字+专属语录）
定制就两步，1分钟搞定：

**第1步：刻名字。** 用任意文本编辑器打开 `无聊罐头.html`，搜索这一行（大概在第 700 行附近）：

```
const OWNER_NAME = "";
```

把买家名字填进引号里，例如：

```
const OWNER_NAME = "给周一不想上班的小王";
```

保存，文件发出去。买家打开后，页面底部和浏览器标题都会出现这行字——这就是"刻在罐头底部"。

**第2步：加专属语录（选做，大杀器）。** 搜索 `radioLines`（收音机的台词库），在第一行引号后面加一句：

```
const radioLines = [
  "小王专属：罐头厂长说了，你今年已经很努力了，剩下的明年再说。",
  ...原有的句子...
];
```

（操作：找到 `const radioLines = [` 这行，在它下一行加 `"你写的那句话",` 即可，注意引号和逗号都要英文的。）

买家拧到收音机听到专属语录的那一瞬间，就是截图发朋友圈的瞬间。这是本产品最强的自传播点。

## 二、买家常见问题话术（直接复制）

**Q：怎么打开？**
> 手机或电脑浏览器直接打开这个文件就行，不用下载任何东西。iPhone 用 Safari，安卓随便哪个浏览器都行。

**Q：会过期吗/能用多久？**
> 永久。文件在你手里，玩到天荒地老。19.9档的以后出新玩具我免费补发你。

**Q：换手机数据还在吗？**
> 进度存在本机浏览器里，换设备会重新开始。不过——木鱼本来讲究的就是从零敲起，功德不带走，才叫功德。

**Q：和免费的解压小程序有什么区别？**

**Q：能便宜点吗？**

**Q：买完打不开/白屏？**
> 别急，99%是文件没下完整。我重新发你一份，记得先保存到本地再打开。还不行的话你截图给我，我一对一处理到你打开为止。

## 四、防坑清单

1. **盗版问题**：网页天然可复制，别纠结。策略是"服务差异化"——你的刻字定制、终身更新、一对一售后才是别人抄不走的。真遇到1:1抄袭，闲鱼举报"盗用图片/文案"即可。
2. **退款问题**：虚拟商品买家原因一般不退，但遇到真的打不开的，秒退。9.9的单不值得耗情绪，时间留着服务下一个。
3. **别承诺医疗效果**：文案里永远不要写"治疗焦虑症/抑郁症/失眠症"。写"解压、放空、治愈、舒服"没问题，写"治"字就是给自己埋雷。已有文案我都避开了，你二次修改时也注意。
4. **别碰"算命/风水改运"方向**：木鱼功德是玩梗，不要往"真能攒功德转运"上引，容易被判封建迷信类目。
5. **发文件建议**：闲鱼站内传文件偶尔抽风，准备一个网盘备用链接（蓝奏云/123云盘，无需登录下载的那种体验最好）。
6. **上新品节奏**：每 2-4 周往罐头里加 1 个新玩具（联系我或其他 AI 都能改这个文件），给老买家免费补发一次——这就是"终身更新"承诺的兑现，也是复购和转介绍的核心。
