## 二、刻字定制操作（29.9 定制款的核心交付）

买家的名字刻在罐头底部落款处，2 分钟搞定：

1. 用文本编辑器（手机用 WPS / 电脑用记事本/VSCode）打开 `无聊罐头.html`
2. 搜索 `OWNER_NAME`（只有一处，在文件开头 script 部分第 30 行左右）
3. 把 `const OWNER_NAME = "";` 改成例如：
   ```js
   const OWNER_NAME = "给周一不想上班的小王";
   ```
4. 保存，这个文件就是小王的专属罐头，发给他

**效果**：页面最底部出现一行橘色字"🥫 给周一不想上班的小王 专属罐头"，浏览器标签页标题也会带上名字。截图发圈传播点极强。

**进阶（可选，收 29.9 值得做）**：在收音机语录里加一句专属话术。搜索 `radioLines`，在数组里任意位置加一行：
```js
"小王，罐头厂长今天也很想你。",
```
买家的收音机里就会随机摇到这句话。

## 三、客服话术（直接复制）

**拍前咨询「这是什么」**：
> 一个装了9个治愈小玩意的网页罐头，手机电脑都能打开，不用下载App。里面有会加功德的木鱼、捏不完的泡泡纸、一块能取名字的石头、一台开往五岁的摇摇车……你先逛逛，觉得可爱再拍～

**拍前咨询「能便宜吗」**：
> 已经是天花板价啦，主要这罐头可以刻你的名字，值回票价。不过你现在拍，我多送你一句专属语录埋在罐头里，慢慢摇出来～

**拍后交付**（手动发货时）：
> 来啦，这是你的罐头 🥫 文件已发你。用手机浏览器（Safari/Chrome）打开就能玩，微信里收到的话点"用其他应用打开→浏览器"。建议戴耳机，音效是罐头的灵魂。记得给它里的石头取个名字～

**催好评**（发货后第二天）：
> 罐头玩得还开心吗？摇摇车今天开往五岁了没🚗 方便的话帮我点个好评，猫厂长会很不加KPI地感谢你～

## 四、售后预案

| 问题 | 回复 |
|------|------|
| "微信里打不开" | "微信不让直接开网页～把文件保存到手机后，点文件→右上角···→用浏览器打开，或发到电脑上双击打开。" |
| "没有声音" | "看下罐头右上角的小喇叭是不是 🔇 状态，点一下变 🔊 就好。另外手机静音键拨了也会没声哦。" |
| "进度没了" | "罐头的记忆存在浏览器里的，如果用'无痕模式'打开或者清理了浏览器数据就会失忆～正常用不会丢。" |
| "苹果手机震动没反应" | "iPhone 不支持网页震动反馈，属于苹果的规矩，音效和画面都不受影响～" |
| 要求退款 | 数字商品，发货前秒退可退；已发货原则上不退（上架描述里写明）。态度差直接退款+拉黑，别纠缠，9.9 的单不值得。 |

## 五、防白嫖 & 防盗

1. **防白嫖**：闲鱼常有"先发我看看效果"→ 收到文件直接确认不付款。回复："罐头封面图和视频都发在页面里了，那已经是全部效果的1/3，剩下的拧开才算数～" 不发文件，只发图。
2. **防盗转卖**：无法完全防止。对策是把价值放在"终身更新 + 刻字服务"上——转卖者拿不到更新，也做不了定制。每次更新玩具时在罐头里换个新彩蛋，老文件会过时。
3. **买家秀即素材**：买家晒的成就墙截图，经同意后就是你下一条抖音的素材，标注"买家来稿"，可信度比自卖自夸高10倍。

## 六、增长路径（第一个月）

- **第1周**：闲鱼上架 9.9 引流款 + 抖音发脚本1。目标：3单+1条500播放。
- **第2周**：根据抖音评论区反馈，把最火的玩具单独剪条视频追发。闲鱼上 19.9 刻字款。
- **第3周**：朋友圈/群发一轮"送你一罐无聊"（免费发文件给10个朋友，换他们晒图）。社交裂变是这个产品的天然优势——成就墙就是设计来晒的。
- **第4周**：复盘。如果单量稳定，考虑：① 开发"节日限定罐头"（中秋罐头=加了月饼配料表）做复购；② 上小红书（文案B直接可用，小红书用户和这个产品气质100%契合）。

**关键心态**：这个产品的边际成本是零，卖出去每一单都是利润。前期别在价格上内耗，把时间花在拍视频上——视频才是流量入口。
